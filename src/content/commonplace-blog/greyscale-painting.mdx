# Greyscale Painting Methods

Greyscale painting separates the development of tonal values
from the application of color.

## Common Approaches

- Painting values first, followed by color adjustments.
- Using blending modes to introduce color.
- Applying gradient maps to individual materials.
- Combining greyscale underpainting with direct painting.

## Considerations

Some color blending methods can affect tonal values,
so adjustments may be necessary to preserve contrast.

Gradient maps offer an alternative for mapping colors
to specific value ranges.
