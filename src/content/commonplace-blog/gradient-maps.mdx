# Gradient Maps in digital-painting

Gradient maps assign colors according to the tonal values
of an image or selected layer.

## Material-Based Workflow

Different materials can use independent gradient maps:

- Skin
- Fabric
- Metal
- Leather

This approach allows each material to have its own
color transitions while retaining the underlying
value structure.

## Combining Techniques

Gradient maps can establish a base color scheme,
followed by direct painting for local adjustments,
reflected light, and color variation.
